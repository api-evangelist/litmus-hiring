# Litmus Hiring

> Litmus is a Y Combinator-backed technical hiring platform that turns repositories, engineering tickets, and job descriptions into structured, project-based technical assessments and interview pipelines. It evaluates candidates on both code quality and development process, captures AI-tool usage (Claude Code, Copilot CLI) transparently, and syncs candidate management with Ashby, Greenhouse, and Lever. It exposes a REST API and an official hosted MCP server.

## APIs
- [Litmus REST API reference](https://litmushiring.com/docs/rest): Base URL https://www.litmushiring.com/api/v1 — roles, invites, submissions. Bearer API key (litmus_sk_...).
- [Litmus MCP server](https://litmushiring.com/docs/mcp): Hosted Model Context Protocol server at https://litmushiring.com/mcp/<org-id>/ — Clerk OAuth or API key.
